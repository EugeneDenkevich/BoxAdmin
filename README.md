# Box Admin Bot
Бот для администрирования группы по боксу.

Фичи:
1. Сам создает пулы. Можно отменять на определенные дни. Можно заранее понять, отменять тренировку или нет.
2. На основе пулов отдает статистику - следим за посещаемостью!
3.

## Команды и роли

- `/start` в личном чате показывает ваш Telegram ID.
- Отдельных slash-команд для staff и admin нет. Staff-пользователи (`is_staff = true`) получают уведомления о неактивных пользователях; чтобы забанить подходящего пользователя, нажмите «Забанить» в уведомлении.
- Admin-пользователь (`is_admin = true`) защищён от бана. Чтобы получать staff-уведомления и использовать кнопку, ему также нужна роль staff (`is_staff = true`).
